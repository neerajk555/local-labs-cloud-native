# 6.3 Scaffolding Your Own Chart

## Concept Recap

Now that you've used a chart, build the skeleton of your own using Helm's built-in generator, and understand what each generated file is for before changing anything.

## Objective

Generate a new chart and understand its default structure.

## Prerequisites

- Lab 6.2 complete

## Steps

### Step 1: Generate a new chart

```bash
helm create mychart
```

### Step 2: Explore its structure

```bash
find mychart -type f | sort
```

### Step 3: Read the key files

- `Chart.yaml` - metadata: name, version, description
- `values.yaml` - the DEFAULT values your templates will use
- `templates/deployment.yaml` - a templated Deployment (uses `{{ .Values.xxx }}` placeholders)
- `templates/service.yaml` - a templated Service
- `templates/_helpers.tpl` - reusable named template snippets (Lab 6.5)

### Step 4: Install the default scaffold as-is

```bash
helm install scaffold-test ./mychart
kubectl get pods -l app.kubernetes.io/instance=scaffold-test
```


## Try It Yourself

**Exercise 1:** Open `mychart/values.yaml` and change `replicaCount` from 1 to 2, then `helm upgrade scaffold-test ./mychart` and confirm the change applied.

<details><summary>Hint (try first without peeking)</summary>

Just edit the YAML value, save, and run `helm upgrade <release> <chart-dir>` - no need to reinstall.

</details>

## Check Your Understanding

**Q1: What command generates a new chart skeleton?**

<details><summary>Answer</summary>

`helm create <chart-name>`.

</details>

**Q2: Which file holds the DEFAULT values a chart's templates will use if you don't override them?**

<details><summary>Answer</summary>

values.yaml.

</details>

**Q3: Can you install the scaffolded chart immediately, without editing anything?**

<details><summary>Answer</summary>

Yes - `helm create` generates a fully working (if generic) chart out of the box, useful for confirming the basics work before customizing.

</details>

## Common Mistakes

- **Deleting files from the generated scaffold before understanding what they do** - Read through each generated file first - even ones you'll eventually simplify or remove, like tests/ or the HPA template.

## Cleanup

```bash
helm uninstall scaffold-test
```
