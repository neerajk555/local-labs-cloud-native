# L3.3: Namespaces and Labels

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Organize resources with namespaces and labels/selectors.

## Prerequisites

- Lab L3.2 complete

## Steps

### Step 1: Create a namespace

```bash
kubectl create namespace demo
```

### Step 2: Deploy into it with labels

```bash
kubectl create deployment web -n demo --image=nginx:1.27
kubectl label deployment web -n demo tier=frontend
```

### Step 3: Select by label

```bash
kubectl get pods -n demo -l tier=frontend
```

## Expected Result

The label selector returns exactly the pods from this deployment.

## Cleanup

```bash
kubectl delete namespace demo
```

## Troubleshooting

- **Selector returns nothing**: Labels on the Deployment don't automatically propagate to Pods — set them in the pod template's `metadata.labels`, too.
