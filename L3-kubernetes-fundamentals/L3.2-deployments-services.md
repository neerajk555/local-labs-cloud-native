# L3.2: Deployments and Services

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Deploy an app and expose it inside the cluster.

## Prerequisites

- Lab L3.1 complete

## Steps

### Step 1: Create a deployment

```bash
kubectl create deployment web --image=nginx:1.27 --replicas=2
```

### Step 2: Expose it

```bash
kubectl expose deployment web --port=80 --type=ClusterIP
```

## Expected Result

`kubectl get pods,svc` shows 2 running pods and one ClusterIP service.

## Cleanup

```bash
kubectl delete deployment,service web
```

## Troubleshooting

- **ImagePullBackOff**: kind nodes need internet access to pull images the first time — check your host's network.
