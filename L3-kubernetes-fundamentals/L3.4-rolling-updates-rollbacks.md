# L3.4: Rolling Updates and Rollbacks

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Update an image with zero downtime and roll back a bad release.

## Prerequisites

- Lab L3.2 complete

## Steps

### Step 1: Update the image

```bash
kubectl set image deployment/web nginx=nginx:1.28
```

### Step 2: Watch the rollout

```bash
kubectl rollout status deployment/web
```

### Step 3: Roll back

```bash
kubectl rollout undo deployment/web
```

## Expected Result

The rollout completes without downtime, and rollback restores the prior image.

## Cleanup

```bash
kubectl delete deployment web
```

## Troubleshooting

- **Rollout never finishes**: Check `kubectl describe deployment/web` for a readiness probe failure on the new image.
