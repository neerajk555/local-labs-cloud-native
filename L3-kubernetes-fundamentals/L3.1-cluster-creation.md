# L3.1: Creating a kind Cluster

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Stand up a local multi-node Kubernetes cluster with `kind`.

## Prerequisites

- kind installed
- kubectl installed
- Docker running

## Steps

### Step 1: Create the cluster

```bash
kind create cluster --name local-lab
```

### Step 2: Verify

```bash
kubectl cluster-info --context kind-local-lab
kubectl get nodes
```

## Expected Result

`kubectl get nodes` shows one or more nodes in `Ready` state.

## Cleanup

```bash
kind delete cluster --name local-lab
```

## Troubleshooting

- **Cluster creation hangs**: Confirm Docker Desktop has enough memory allocated (4GB+ recommended) in its resource settings.
