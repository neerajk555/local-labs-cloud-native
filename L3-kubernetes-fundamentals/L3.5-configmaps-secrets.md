# L3.5: ConfigMaps and Secrets

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Externalize configuration and sensitive values.

## Prerequisites

- Lab L3.2 complete

## Steps

### Step 1: Create a ConfigMap and Secret

```bash
kubectl create configmap app-config --from-literal=GREETING=hello
kubectl create secret generic app-secret --from-literal=API_KEY=demo123
```

### Step 2: Mount as env vars

```bash
kubectl set env deployment/web --from=configmap/app-config
kubectl set env deployment/web --from=secret/app-secret
```

## Expected Result

`kubectl exec` into a pod shows both environment variables set.

## Cleanup

```bash
kubectl delete configmap app-config
kubectl delete secret app-secret
```

## Troubleshooting

- **Values not updated**: Deployments don't auto-restart on ConfigMap/Secret change — `kubectl rollout restart deployment/web`.
