# L6.4: Self-Signed TLS

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Terminate TLS at the ingress using a self-signed certificate.

## Prerequisites

- Lab L6.2 complete
- openssl installed

## Steps

### Step 1: Generate a self-signed cert

```bash
openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout tls.key -out tls.crt -subj '/CN=a.local'
```

### Step 2: Create a TLS secret

```bash
kubectl create secret tls a-local-tls --cert=tls.crt --key=tls.key
```

### Step 3: Reference it in the Ingress and test

```bash
kubectl apply -f ingress-tls.yaml
curl -k -H 'Host: a.local' https://localhost/
```

## Expected Result

The HTTPS request succeeds with `-k` (ignoring the self-signed cert warning) and returns the expected backend response.

## Cleanup

```bash
kubectl delete secret a-local-tls
kubectl delete ingress tls-demo
```

## Troubleshooting

- **curl SSL errors without -k**: Expected — it's self-signed and not in your trust store. That's fine for a local lab.
