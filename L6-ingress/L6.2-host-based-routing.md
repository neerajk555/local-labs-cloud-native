# L6.2: Host-Based Routing

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Route two different hostnames to two different services.

## Prerequisites

- Lab L6.1 complete

## Steps

### Step 1: Deploy two backends

```bash
kubectl create deployment app-a --image=hashicorp/http-echo -- -text='app-a'
kubectl create deployment app-b --image=hashicorp/http-echo -- -text='app-b'
kubectl expose deployment app-a --port=5678
kubectl expose deployment app-b --port=5678
```

### Step 2: Create a host-based Ingress

```bash
kubectl apply -f ingress-host-based.yaml
```

### Step 3: Test with Host headers

```bash
curl -H 'Host: a.local' http://localhost/
curl -H 'Host: b.local' http://localhost/
```

## Expected Result

The two requests return `app-a` and `app-b` respectively.

## Cleanup

```bash
kubectl delete ingress host-based
kubectl delete deployment,service app-a app-b
```

## Troubleshooting

- **Both return the same app**: Double-check the `host:` field under each Ingress rule matches the `Host` header exactly, including case.
