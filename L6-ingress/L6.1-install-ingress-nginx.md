# L6.1: Installing ingress-nginx on kind

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Install the ingress-nginx controller on a kind cluster configured for it.

## Prerequisites

- kind cluster created with extraPortMappings for 80/443 (see kind config sample)

## Steps

### Step 1: Install the controller

```bash
kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/main/deploy/static/provider/kind/deploy.yaml
```

### Step 2: Wait for it to be ready

```bash
kubectl wait --namespace ingress-nginx --for=condition=ready pod --selector=app.kubernetes.io/component=controller --timeout=120s
```

## Expected Result

The ingress-nginx controller pod reaches `Running` and `Ready`.

## Cleanup

```bash
kubectl delete -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/main/deploy/static/provider/kind/deploy.yaml
```

## Troubleshooting

- **Controller never becomes ready**: kind needs a cluster config with `extraPortMappings` for 80/443 on the control-plane node — a plain `kind create cluster` won't work for ingress.
