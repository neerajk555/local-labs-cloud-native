# L6.3: Path-Based Routing

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Route different URL paths on the same host to different services.

## Prerequisites

- Lab L6.2 complete

## Steps

### Step 1: Create a path-based Ingress

```bash
kubectl apply -f ingress-path-based.yaml
```

### Step 2: Test each path

```bash
curl http://localhost/a
curl http://localhost/b
```

## Expected Result

`/a` and `/b` return different backends' responses.

## Cleanup

```bash
kubectl delete ingress path-based
```

## Troubleshooting

- **404 on a path**: Confirm `pathType: Prefix` (not `Exact`) if you want `/a/anything` to also match.
