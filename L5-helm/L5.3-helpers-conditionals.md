# L5.3: Helpers and Conditionals

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Add a named template helper and a conditional block.

## Prerequisites

- Lab L5.2 complete

## Steps

### Step 1: Add a helper in _helpers.tpl

```bash
cat >> mychart/templates/_helpers.tpl <<'EOF'
{{- define "mychart.fullname" -}}
{{ .Release.Name }}-{{ .Chart.Name }}
{{- end -}}
EOF
```

### Step 2: Use it with a conditional

```bash
# {{- if .Values.ingress.enabled }} ... {{- end }}
```

## Expected Result

Rendering with `--set ingress.enabled=true` includes the Ingress block; without it, the block is omitted.

## Cleanup

```bash
N/A
```

## Troubleshooting

- **Helper not found**: Named templates must be defined before `helm template`/`helm install` renders anything referencing them — any file in templates/ is fine, order doesn't matter within a single render pass.
