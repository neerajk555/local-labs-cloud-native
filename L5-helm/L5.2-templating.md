# L5.2: Templating Values

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Parameterize a manifest using Helm's Go templating and values.yaml.

## Prerequisites

- Lab L5.1 complete

## Steps

### Step 1: Edit values.yaml

```bash
sed -i 's/replicaCount: 1/replicaCount: 3/' mychart/values.yaml
```

### Step 2: Render and inspect

```bash
helm template mychart | grep replicas
```

## Expected Result

The rendered manifest shows `replicas: 3`.

## Cleanup

```bash
N/A — no cluster resources created yet.
```

## Troubleshooting

- **Template renders blank**: Check for a typo in the `{{ .Values.xxx }}` path against the actual key name in values.yaml.
