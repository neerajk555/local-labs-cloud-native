# L5.1: Scaffolding a Chart

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Generate and inspect a new Helm chart's structure.

## Prerequisites

- Helm installed
- Lab L3.1 complete

## Steps

### Step 1: Create a chart

```bash
helm create mychart
```

### Step 2: Inspect the structure

```bash
find mychart -type f
```

## Expected Result

You see `Chart.yaml`, `values.yaml`, and a `templates/` directory.

## Cleanup

```bash
rm -rf mychart
```

## Troubleshooting

- **helm not found**: Reinstall via your package manager and confirm it's on PATH.
