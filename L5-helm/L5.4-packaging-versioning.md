# L5.4: Packaging and Versioning

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Package the chart and install/upgrade it with version tracking.

## Prerequisites

- Lab L5.3 complete
- Lab L3.1 complete

## Steps

### Step 1: Package it

```bash
helm package mychart
```

### Step 2: Install it

```bash
helm install myrelease ./mychart-0.1.0.tgz
```

### Step 3: Bump the version and upgrade

```bash
sed -i 's/version: 0.1.0/version: 0.2.0/' mychart/Chart.yaml
helm package mychart
helm upgrade myrelease ./mychart-0.2.0.tgz
```

## Expected Result

`helm history myrelease` shows two revisions.

## Cleanup

```bash
helm uninstall myrelease
rm mychart-*.tgz
```

## Troubleshooting

- **Upgrade no-ops**: Helm skips no-op upgrades if nothing in the rendered manifest actually changed — bump something functional, not just the version string, to see a real rollout.
