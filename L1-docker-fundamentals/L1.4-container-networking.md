# L1.4: Container Networking

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Create a user-defined bridge network and connect two containers by name.

## Prerequisites

- Docker installed

## Steps

### Step 1: Create a network

```bash
docker network create l1-net
```

### Step 2: Run two containers on it

```bash
docker run -d --name l1-web --network l1-net nginx
docker run -it --rm --network l1-net alpine ping -c 3 l1-web
```

## Expected Result

The alpine container successfully pings `l1-web` by container name.

## Cleanup

```bash
docker rm -f l1-web
docker network rm l1-net
```

## Troubleshooting

- **Name resolution fails**: Only user-defined networks (not the default bridge) support automatic DNS between containers.
