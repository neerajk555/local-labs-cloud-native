# L1.3: Resource Limits

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Cap a container's CPU and memory to prevent it from starving the host.

## Prerequisites

- Docker installed

## Steps

### Step 1: Run with limits

```bash
docker run -d --name l1-limits --memory=128m --cpus=0.5 nginx
```

### Step 2: Verify the limits took effect

```bash
docker inspect l1-limits --format='{{.HostConfig.Memory}} {{.HostConfig.NanoCpus}}'
```

## Expected Result

Memory shows 134217728 (128MB in bytes) and CPU shows the nanocpu equivalent of 0.5.

## Cleanup

```bash
docker rm -f l1-limits
```

## Troubleshooting

- **Container OOM-killed**: That's the limit working as intended — raise `--memory` if the app genuinely needs more.
