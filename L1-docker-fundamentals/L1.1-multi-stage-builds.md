# L1.1: Multi-Stage Builds

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Shrink an image using a build stage and a slim runtime stage.

## Prerequisites

- Docker installed

## Steps

### Step 1: Write a multi-stage Dockerfile

```bash
cat > Dockerfile <<'EOF'
FROM node:20 AS build
WORKDIR /app
COPY . .
RUN npm install --production

FROM node:20-slim
WORKDIR /app
COPY --from=build /app .
CMD ["node", "index.js"]
EOF
```

### Step 2: Build and compare

```bash
docker build -t l1-demo .
docker images l1-demo
```

## Expected Result

The final image is meaningfully smaller than a single-stage build.

## Cleanup

```bash
docker rmi l1-demo
```

## Troubleshooting

- **COPY --from fails**: Stage names are case-sensitive; confirm `AS build` matches `--from=build`.
