# L1.2: Health Checks and Restart Policies

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Configure a container health check and an automatic restart policy.

## Prerequisites

- Docker installed

## Steps

### Step 1: Run with a health check

```bash
docker run -d --name l1-health --health-cmd='curl -f http://localhost/ || exit 1' --health-interval=10s --restart=unless-stopped nginx
```

### Step 2: Inspect health status

```bash
docker inspect --format='{{.State.Health.Status}}' l1-health
```

## Expected Result

Status reports `healthy` after the first interval.

## Cleanup

```bash
docker rm -f l1-health
```

## Troubleshooting

- **Status stuck starting**: The first health check only runs after `--health-start-period` (default a few seconds) elapses.
