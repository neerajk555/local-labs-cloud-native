# L4.3: Persistent Volumes and Claims

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Give a pod durable storage that survives pod restarts.

## Prerequisites

- Lab L3.1 complete

## Steps

### Step 1: Create a PVC (kind's default StorageClass provisions automatically)

```bash
kubectl apply -f pvc.yaml
```

### Step 2: Mount it in a pod and write data

```bash
kubectl apply -f pod-with-pvc.yaml
kubectl exec pvc-demo -- sh -c 'echo persisted > /data/file.txt'
```

### Step 3: Delete and recreate the pod

```bash
kubectl delete pod pvc-demo
kubectl apply -f pod-with-pvc.yaml
kubectl exec pvc-demo -- cat /data/file.txt
```

## Expected Result

The file written before the pod was deleted is still there after recreation.

## Cleanup

```bash
kubectl delete pod pvc-demo
kubectl delete pvc pvc-demo-claim
```

## Troubleshooting

- **PVC stuck Pending**: Confirm kind's default StorageClass exists: `kubectl get storageclass`.
