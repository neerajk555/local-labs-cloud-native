# L4.2: StatefulSets

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Deploy a stateful app with stable network identity and ordered startup.

## Prerequisites

- Lab L3.1 complete

## Steps

### Step 1: Apply a StatefulSet manifest

```bash
kubectl apply -f statefulset.yaml
```

### Step 2: Observe stable pod names

```bash
kubectl get pods -l app=stateful-demo -w
```

## Expected Result

Pods are named `stateful-demo-0`, `stateful-demo-1`, etc., and start in order.

## Cleanup

```bash
kubectl delete statefulset stateful-demo
```

## Troubleshooting

- **Pods stuck Pending**: StatefulSets need a matching headless Service (`clusterIP: None`) — confirm it exists.
