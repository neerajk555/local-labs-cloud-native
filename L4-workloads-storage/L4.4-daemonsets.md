# L4.4: DaemonSets

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Run exactly one copy of a pod on every node in the cluster.

## Prerequisites

- A multi-node kind cluster (recreate Lab L3.1 with a kind config specifying extra worker nodes)

## Steps

### Step 1: Apply a DaemonSet manifest

```bash
kubectl apply -f daemonset.yaml
```

### Step 2: Verify one pod per node

```bash
kubectl get pods -o wide -l app=node-agent
```

## Expected Result

Exactly one `node-agent` pod is running per node.

## Cleanup

```bash
kubectl delete daemonset node-agent
```

## Troubleshooting

- **Only one pod total**: A single-node kind cluster only ever schedules one DaemonSet pod — recreate the cluster with extra worker nodes to see the pattern properly.
