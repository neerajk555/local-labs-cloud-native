# L4.1: Jobs and CronJobs

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Run a one-off batch task and a scheduled recurring task.

## Prerequisites

- Lab L3.1 complete

## Steps

### Step 1: Run a Job

```bash
kubectl create job hello-job --image=busybox -- echo hello
```

### Step 2: Create a CronJob

```bash
kubectl create cronjob hello-cron --image=busybox --schedule='*/2 * * * *' -- echo hello
```

## Expected Result

The Job completes once; the CronJob spawns a new Job every 2 minutes.

## Cleanup

```bash
kubectl delete job hello-job
kubectl delete cronjob hello-cron
```

## Troubleshooting

- **CronJob never fires**: kind's clock follows the host — confirm your host system time is correct.
