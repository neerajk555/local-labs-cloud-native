# L2.2: Three-Tier App with Cache-Aside

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Wire an app tier to a cache tier and a database tier, implementing cache-aside.

## Prerequisites

- Lab L2.1 complete

## Steps

### Step 1: Add a db service and app service to compose.yaml

```bash
# app service checks cache, falls back to db on miss, then populates cache
```

### Step 2: Bring it up and hit the app twice

```bash
docker compose up -d
curl http://localhost:8080/data
curl http://localhost:8080/data
```

## Expected Result

The second request is visibly faster and the cache shows a hit.

## Cleanup

```bash
docker compose down -v
```

## Troubleshooting

- **Cache never populated**: Confirm the app's cache-set call runs on the miss path before returning the response.
