# L2.3: Environment Files and Variable Substitution

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Externalize configuration into a `.env` file used by Compose.

## Prerequisites

- Lab L2.1 complete

## Steps

### Step 1: Create .env

```bash
echo 'WEB_PORT=8080' > .env
```

### Step 2: Reference it in compose.yaml

```bash
# ports:
#   - "${WEB_PORT}:80"
```

### Step 3: Bring it up

```bash
docker compose up -d
```

## Expected Result

Changing `.env` and re-running `docker compose up -d` changes the exposed port without editing compose.yaml.

## Cleanup

```bash
docker compose down
```

## Troubleshooting

- **Variable not substituted**: Compose only reads `.env` from the same directory as the compose file, by default.
