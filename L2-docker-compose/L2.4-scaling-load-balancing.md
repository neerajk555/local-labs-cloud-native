# L2.4: Scaling and Manual Load Balancing

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Scale a service to multiple replicas and balance requests across them.

## Prerequisites

- Lab L2.1 complete

## Steps

### Step 1: Scale the web service

```bash
docker compose up -d --scale web=3
```

### Step 2: Add a simple nginx load balancer in front

```bash
# lb service depends_on web, round-robins via upstream block
```

## Expected Result

Repeated requests to the load balancer are served by different `web` replicas (visible via a per-replica identifier in the response).

## Cleanup

```bash
docker compose down
```

## Troubleshooting

- **All requests hit the same replica**: Docker's embedded DNS round-robins per new connection, not per request — use `curl` in a loop with `--no-keepalive` to see the distribution.
