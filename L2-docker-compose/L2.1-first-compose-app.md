# L2.1: Your First Compose App

**Cost:** Free (runs entirely on your own machine)
**Time:** ~15 min

## Objective

Bring up a two-service app (web + Redis) with one command.

## Prerequisites

- Docker Compose v2 (bundled with Docker Desktop)

## Steps

### Step 1: Write compose.yaml

```bash
cat > compose.yaml <<'EOF'
services:
  web:
    image: nginx
    ports:
      - "8080:80"
  cache:
    image: redis:7
EOF
```

### Step 2: Bring it up

```bash
docker compose up -d
docker compose ps
```

## Expected Result

Both services show as running; http://localhost:8080 serves nginx's welcome page.

## Cleanup

```bash
docker compose down
```

## Troubleshooting

- **Port already in use**: Change the host-side port, e.g. `8081:80`, if 8080 is taken.
